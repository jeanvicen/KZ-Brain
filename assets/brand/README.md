# Identidade visual

Identidade visual original do KZ-Brain. O símbolo representa módulos conectados a um núcleo, sem retratar anatomia humana.

- `kz-brain-icon.svg` — ícone principal.
- `kz-brain-horizontal-dark.svg` — wordmark para fundo escuro.
- `kz-brain-horizontal-light.svg` — wordmark para fundo claro.
- `kz-brain-monochrome.svg` — símbolo monocromático escalável.
- `favicon.svg` — favicon vetorial.

Paleta conceitual: azul-noite `#0B1220`, verde-água `#7DE2D1`, índigo `#7B8CFF`, branco frio `#F4F8FF`. Use com contraste acessível; não aplicar efeitos que alterem o desenho-base.
