# Agentes especializados

> **Status:** Foundation / Architecture Stage — conceptual documentation only. No runtime behavior is implemented here.

## Objective
Descrever papéis futuros sem criar agentes funcionais.

## Scope
Planner, Researcher, Coder, Analyst, Writer, Vision, Audio, Data, Security e Executor.

## Responsibilities
Definir limites de tarefa, roteamento, handoff, contexto, permissões e aprovação humana.

## Conceptual inputs
Tarefas autorizadas e plano supervisionado.

## Conceptual outputs
Resultados parciais revisados, erros recuperáveis ou escalonamento.

## Dependencies and relationships
Orchestration, tools, memory, multimodal e security.

## Risks and open questions
Ações fora de escopo, loops, instruções maliciosas e perda de auditabilidade.

## Future evolution
Começar com capacidades restritas, dry-run, logs redigidos e gates humanos.

## Current boundary
This document reserves an architectural space; it does not claim that the capability exists. Any future implementation requires an explicit design, threat analysis, evaluation plan, and review before code is added.
