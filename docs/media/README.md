# Mídia e identidade visual

A identidade do KZ-Brain é original e produzida para esta fundação. Arquivos-base estão em [`../../assets/brand/`](../../assets/brand/); os diagramas Mermaid são a fonte editável dos diagramas arquiteturais.

## Estratégia de imagens

A identidade deve priorizar SVGs e diagramas próprios para hero, arquitetura, memória, ferramentas, agentes, multimodalidade, ciclo de treinamento/inferência, roadmap e ecossistema. Não utilizar marcas de terceiros como se fizessem parte do KZ-Brain.

## Fontes externas

Até esta revisão, não foram incorporadas imagens, vídeos ou logos externos.
