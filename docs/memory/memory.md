# Memória

> **Status:** Foundation / Architecture Stage — conceptual documentation only. No runtime behavior is implemented here.

## Objective
Descrever os tipos de memória planejados e suas políticas.

## Scope
Working, Session, Semantic, Episodic, Long-Term, Knowledge, Tool Memory e User Context.

## Responsibilities
Definir escopo, retenção, expiração, recuperação, isolamento, versionamento e consentimento futuro.

## Conceptual inputs
Informação mínima e explicitamente autorizada.

## Conceptual outputs
Contexto selecionado com proveniência e opções de exclusão.

## Dependencies and relationships
Arquitetura de memória, contexto, segurança, APIs e armazenamento futuro.

## Risks and open questions
Retenção oculta, inferência de dados sensíveis e cross-user leakage.

## Future evolution
Exigir consentimento explícito, políticas por classe e testes de isolamento antes de implementação.

## Current boundary
This document reserves an architectural space; it does not claim that the capability exists. Any future implementation requires an explicit design, threat analysis, evaluation plan, and review before code is added.
