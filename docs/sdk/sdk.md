# SDK

> **Status:** Foundation / Architecture Stage — conceptual documentation only. No runtime behavior is implemented here.

## Objective
Planejar bibliotecas cliente em Python e JavaScript.

## Scope
Interfaces e distribuição futura; nenhum pacote é publicado.

## Responsibilities
Documentar autenticação segura, timeouts, erros, tipagem e compatibilidade.

## Conceptual inputs
API estável e OpenAPI/schema aprovado futuramente.

## Conceptual outputs
Abstração cliente versionada e exemplos verificáveis.

## Dependencies and relationships
API, release, security e docs.

## Risks and open questions
Segredos embutidos, divergência do servidor e promessas sem suporte.

## Future evolution
Gerar/validar SDKs contra contratos e manter política de versões.

## Current boundary
This document reserves an architectural space; it does not claim that the capability exists. Any future implementation requires an explicit design, threat analysis, evaluation plan, and review before code is added.
