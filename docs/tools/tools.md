# Ferramentas

> **Status:** Foundation / Architecture Stage — conceptual documentation only. No runtime behavior is implemented here.

## Objective
Catalogar categorias e controles para futuras ferramentas.

## Scope
Web, search, browser, files, code, shell, database, GitHub, storage, documents, image, audio, video, messaging, automation, MCP e ferramentas customizadas.

## Responsibilities
Registro, discovery, permissão, execução isolada, validação e telemetria.

## Conceptual inputs
Schema de pedido, identidade e autorização.

## Conceptual outputs
Resultado tipado, erro ou solicitação de aprovação.

## Dependencies and relationships
Orquestração, conectores, segurança e observabilidade.

## Risks and open questions
Efeitos externos irreversíveis, execução arbitrária e exfiltração.

## Future evolution
Começar sem side effects, adotar allowlists e confirmação para ações relevantes.

## Current boundary
This document reserves an architectural space; it does not claim that the capability exists. Any future implementation requires an explicit design, threat analysis, evaluation plan, and review before code is added.
